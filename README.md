# Fall Bingo Tracker

Live tracker for the Fall Bingo event (November 2026, now concluded):
team standings, tile progress, player stats and proof screenshots.

- `index.html` - the tracker page, served via GitHub Pages
- `data.json` - event data: teams, tiles, players, screenshots
- `assets/` - tile art, screenshots and map images

Final standings are preserved as of the event close.
